# User Registration

## Overview

AM comes with a basic user registration feature.

## Enable user registration

1. Log in to AM Console.
2.  Click **Settings > Login** and toggle on the **User registration** switch.

    <figure><img src="../../.gitbook/assets/graviteeio-am-userguide-um-registration-settings.png" alt="The domain Login settings with User registration switched on and forgot password and passwordless switched off."><figcaption><p>Enable user registration</p></figcaption></figure>

A new `Register` link will be available on the login form.

<figure><img src="../../.gitbook/assets/graviteeio-am-userguide-um-registration-login.png" alt="The Sign in page with username and password fields above a Register link."><figcaption><p>Sign in register link</p></figcaption></figure>

The link will redirect the user to the registration page to create an account.

<figure><img src="../../.gitbook/assets/graviteeio-am-userguide-um-registration-form.png" alt="The Sign up form with first name, last name, username, email address, and password fields, above Back to login and Create account."><figcaption><p>Create a new account</p></figcaption></figure>

{% hint style="info" %}
You can change the look and feel of the login form and registration form. See [Custom forms](../branding/README.md#custom-pages) for more information.
{% endhint %}
