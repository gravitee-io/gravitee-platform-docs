# APIs

The **APIs** group of the Event Stream Management sidebar holds the two API types that the module governs.

* [**Kafka Services**](kafka-services/README.md). A Kafka Service exposes a registered cluster or a Virtual Cluster to Kafka clients, which connect to the Event Gateway with the Kafka protocol.
* [**Message APIs**](message-apis/README.md). A Message API connects clients to a message backend such as Kafka, MQTT 5.x, Solace, or RabbitMQ through entrypoints such as HTTP GET, Server-Sent Events, or Webhook.
