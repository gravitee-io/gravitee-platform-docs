The **Schemas** item of the **Policy Structure** group opens the **Schema** page, which holds your schema documents.

* [**Schema documents**](schema-generation.md). What a document declares, which gateways receive it, and where two documents meet.
* [**Create and edit schema documents**](edit-your-schema.md). Write a document, assign it to a PDP gateway, and save it.
* [**Validate schema changes**](validate-schema-changes.md). The errors and warnings that the editor and a save report, and how to fix them.
