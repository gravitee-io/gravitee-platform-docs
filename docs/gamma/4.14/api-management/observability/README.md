# Observe

The **Observability** group of the API Management sidebar holds the **Dashboards**, **Logs**, and **Tracing** pages.

* [**Dashboard and metrics**](../observe/api-dashboard.md). The Gamma homepage dashboard shows per-module metrics, quick actions, and guidance for empty states.
* [**Monitor API usage**](../observe/monitor-api-usage.md). Track request volume, latency distribution, error rates, and top consumers for an API proxy.
* [**View API logs**](../observe/view-api-logs.md). Inspect individual request logs and full request traces for an API proxy in the Trace Explorer.
