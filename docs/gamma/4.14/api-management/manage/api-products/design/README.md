# Design

The **Design** group of an API Product's sidebar holds the **Resources** page.

* [**Configure API Product resources**](../../../build/configure-your-api-product/configure-api-product-resources.md). Add the resources that the policies of an API Product use, such as caches, OAuth2 providers, and authentication providers.
