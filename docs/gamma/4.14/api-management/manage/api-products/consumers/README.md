# Consumers

The **Consumers** group of an API Product's sidebar holds the **Plans**, **Policy Studio**, and **Subscriptions** pages.

* [**Design API Product flows**](../../../build/configure-your-api-product/design-api-product-flows.md). Add flows and policies that run on every API of the API Product, for the requests that come through its plans.
