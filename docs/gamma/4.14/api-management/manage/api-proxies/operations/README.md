# Operate

The **Operations** group of an API proxy's sidebar holds the **Sharding Tags**, **Deployment History**, and **Reporter Settings** pages.

* [**Configure deployment**](../../../build/configure-your-api-proxy/configure-deployment.md). Choose which API Gateway instances load an API definition by assigning sharding tags.
* [**Review deployment history**](../../../build/configure-your-api-proxy/review-deployment-history.md). Compare two deployed versions of an API definition and roll back to an earlier one.
* [**Configure logging and tracing**](../../../build/configure-your-api-proxy/configure-logging-and-tracing.md). Control which request and response data an API proxy reports to logs and analytics, and turn on OpenTelemetry tracing.
