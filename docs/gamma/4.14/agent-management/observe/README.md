# Agent Management observability

The **Observability** group of the Agent Management sidebar holds the **Dashboards**, **Logs**, **Tracing**, **Decisions**, and **Settings** pages. The **Settings** page lists the additional metrics of the environment that belong to LLM, MCP, or A2A proxies or to no API type, read-only. **Decisions** shows only for a role that can read guardrails. To change them, see [Configure additional metrics](https://documentation.gravitee.io/platform-management/environment/system-and-security/configure-additional-metrics).

* [**Dashboards**](dashboards/README.md). Read the dashboards that report AI traffic, cost, and tool usage across proxies and employee devices, or build your own.
* [**Logs**](logs/README.md). Trace an individual invocation through the AI Gateway from its log entry.
* [**Review audit logs**](review-audit-logs.md). Review the configuration audit trail of an LLM Proxy, MCP Proxy, or A2A Proxy from the Audit Logs page of the proxy detail view.
