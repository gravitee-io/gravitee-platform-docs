# Consumers

The **Consumers** group of an A2A Proxy holds the **Plans**, **Subscriptions**, and **Broadcasts** pages.

* [**Manage A2A Proxy plans**](../../configure-your-a2a-proxy/manage-a2a-proxy-plans.md). Create, edit, publish, deprecate, and close the plans that control how consumers authenticate to the proxy.
* [**Manage subscriptions**](../../../publish/manage-subscriptions.md). Subscribe an application to a plan, approve the request, and find the credential the AI Gateway checks.
