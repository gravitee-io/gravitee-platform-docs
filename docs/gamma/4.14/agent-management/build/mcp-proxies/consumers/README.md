# Consumers

The **Consumers** group of an MCP Proxy holds the **Plans**, **Subscriptions**, and **Broadcasts** pages, and the shared [Manage subscriptions](../../../publish/manage-subscriptions.md) and [Broadcast messages to proxy consumers](../../broadcast-messages-to-proxy-consumers.md) guides cover the last two.

* [**Manage MCP Proxy plans**](../../configure-your-mcp/manage-mcp-proxy-plans.md). Create, publish, deprecate, and close the plans that set how consumers authenticate to the proxy.
