# Monitor

The **Monitoring** group of an MCP Proxy holds its **Notifications**, **Alerts**, and **Audit Logs** pages, and the shared [Review audit logs](../../../observe/review-audit-logs.md) guide covers the **Audit Logs** page.

* [**Configure MCP Proxy notifications**](../../configure-mcp-proxy-notifications.md). Choose which API events send notifications for an MCP Proxy and where they are delivered.
* [**Configure MCP Proxy alerts**](../../configure-mcp-proxy-alerts.md). Get notified when the traffic of an MCP Proxy matches an alert rule.
