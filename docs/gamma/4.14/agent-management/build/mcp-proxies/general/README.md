# General

The **General** group of an MCP Proxy holds its **Overview**, **Settings**, **User Permissions**, **Metadata**, and **API Score** pages. **API Score** appears only when API Score is turned on for the environment. The shared [Manage user permissions for your proxies](../../manage-user-permissions-for-your-proxies.md) guide covers the **User Permissions** page, and the shared [Manage metadata for your proxies](../../manage-metadata-for-your-proxies.md) guide covers the **Metadata** page.

* [**Review the MCP Proxy API Score**](../../review-the-mcp-proxy-api-score.md). Evaluate the MCP Proxy against the rulesets of its environment and read the findings.
