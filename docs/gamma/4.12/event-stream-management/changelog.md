# Changelog

This page lists Event Stream Management updates as they ship every two weeks. For the quarterly, cross-module summary, see [Gamma Release Notes](../platform-management/gamma-release-notes.md).

***

## 1.2.0 — July 13, 2026

<details>

<summary>Improvements</summary>

* Policy Studio now receives API resources for its resource pickers.
* Virtual cluster lifecycle rules are now surfaced in the ESM UI.

</details>

## 1.1.1 — July 8, 2026

<details>

<summary>Bug Fixes</summary>

* Hid the Kafka Explorer entry from navigation.

</details>

## 1.1.0 — July 8, 2026

<details>

<summary>Bug Fixes</summary>

* Corrected consumer-group lag and topic count when a topic filter is applied.
* Hardened explorer error handling and tail lifecycle, and bundled Kafka compression codecs in the plugin.

</details>

<details>

<summary>Improvements</summary>

* Added the Kafka Explorer: browse topics, messages, and configs with sortable, fully clickable rows and a contains-match consumer-group topic filter.

</details>

## 1.0.1 — July 6, 2026

<details>

<summary>Bug Fixes</summary>

* Duplicating a Kafka Service now requires a unique listener host.

</details>

## 1.0.0 — June 26, 2026

<details>

<summary>Improvements</summary>

* Initial release of Event Stream Management: Kafka Services and clusters, a creation wizard with SASL/SSL options, and virtual cluster flows.

</details>
