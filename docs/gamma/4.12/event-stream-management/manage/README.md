# Manage

The **Manage** group of the Event Stream Management sidebar holds the **Clusters** pages.

* [**Register your Kafka clusters**](../import/register-your-kafka-clusters.md). Register an existing Kafka cluster with Gamma so Kafka Services and Virtual Clusters can be built on it.
