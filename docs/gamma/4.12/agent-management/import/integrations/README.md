# Integrations

Integrations bring entities from outside Gamma into the Catalog. Model integrations connect an upstream AI platform and import the models it offers. Agents are registered one at a time, from the A2A agent card each one publishes, or discovered as shadow AI agents from the domains the Edge Daemon detects.

* [**Connect integrations**](../connect-integrations.md): Connect Gamma to a model provider or to Azure AI Foundry so their models import into the Catalog.
* [**Register an agent**](../import-an-agent.md): Add an external agent to the Catalog from the A2A agent card it publishes.
* [**Discover shadow AI agents from Edge Management**](../discover-shadow-ai-agents-from-edge-management.md): Turn the AI provider domains the Edge Daemon detects into shadow AI agents in the Catalog.
