# Integrations

Integrations bring entities from outside Gamma into the Catalog. Model integrations connect an upstream AI platform and import the models it offers. Agent platform integrations connect a project on Azure AI Foundry or Gemini Enterprise Agent Platform and sync its agents. Agents can also be registered one at a time, from the A2A agent card each one publishes.

* [**Connect integrations**](../connect-integrations.md): Connect Gamma to a model provider or to Azure AI Foundry so their models import into the Catalog.
* [**Connect an agent platform**](../connect-an-agent-platform.md): Connect an Azure AI Foundry or Gemini Enterprise Agent Platform project and sync its agents into the Catalog.
* [**Register an agent**](../import-an-agent.md): Add an external agent to the Catalog from the A2A agent card it publishes.
