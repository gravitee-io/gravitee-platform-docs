# Integrations

Integrations connect Gamma to the upstream AI platforms that hold your models and agents, so their entities import into the Catalog and come under governance.

* [**Connect integrations**](../connect-integrations.md): Connect Gamma to an AI model provider or to Azure AI Foundry so their models import into the Catalog.
* [**Register an agent**](../import-an-agent.md): Add an agent to the Catalog so policies, observability, and cost attribution can reference it.
