# Tracing

The Trace Explorer holds the OpenTelemetry traces recorded for a proxy, and opens each trace as a span timeline or as a lineage graph of its spans.

* [**Trace an agent request and view its lineage**](../trace-an-agent-request.md): Open a trace for a proxy, read its timeline and lineage graph, and inspect a single span.
