# Govern

Score every agent in your estate against the built-in EU AI Act framework and rulesets of your own. Rate each agent's risk, and hold what agents do to your rules.

* [**Score agent compliance with the EU AI Act framework**](score-agent-compliance-with-the-eu-ai-act.md): activate the built-in framework, read the verdict it computes for every agent, close the gaps it lists on an agent, and export the evidence for an auditor.
* [**Rate an agent's risk level**](rate-an-agents-risk-level.md): set the agent's risk classification on its Overview page, where the framework, the Agents list, and the estate tables read it.
* [**Create a custom compliance ruleset**](create-a-custom-compliance-ruleset.md): check every agent's metadata or the policies on its proxies against rules of your own, and run the ruleset on demand.
* [**View the lineage of an agent or a proxy**](view-agent-lineage.md): walk what an agent or a proxy depended on, reconstructed from gateway traffic over a time window.
* [**Guard agent actions with Guardian Agents**](guard-agent-actions-with-guardian-agents.md): bind a Guardian into the MCP proxy policy chain so every intended action is judged in context before it executes.
* [**Require human approval for MCP tool calls**](require-human-approval-for-mcp-tool-calls.md): declare approval rules against MCP tools so sensitive calls wait for a human decision before they execute.
* [**Agent activity**](agent-activity-logs.md): read the record of one request an agent handled, with the calls it made through the AI Gateway and every decision a rule, a Guardian, or a person took on it.
