# Operations

The Operations group of an LLM Proxy controls which gateway instances load it, and keeps the record of every version it has run.

* [**Configure LLM Proxy deployment**](../../configure-llm-proxy-deployment.md): Choose which gateway instances load an LLM Proxy by assigning sharding tags.
* [**Review LLM Proxy deployment history**](../../review-llm-proxy-deployment-history.md): Inspect or compare versions of an LLM Proxy, and roll back to an earlier API definition.
