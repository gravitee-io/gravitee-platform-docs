# Connect and consume third-party AI tools

External tools and frameworks reach your models through an LLM Proxy, so the gateway holds the provider credential and governs every call they make.

* [**Connect Claude Code through an LLM Proxy**](../../../publish/connect-claude-code-through-an-llm-proxy.md): Point Claude Code at an LLM Proxy so its traffic is governed and attributed.
* [**Consume your LLM Proxy with LangChain**](../../../publish/consume-your-llm-proxy-with-langchain.md): Route a LangChain chain through your LLM Proxy so it never holds a provider credential.
