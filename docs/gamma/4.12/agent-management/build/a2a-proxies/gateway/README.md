The Gateway group of an A2A Proxy controls how the gateway handles its traffic, and what it reports about every call.

* [**Configure logging and tracing**](../../configure-your-a2a-proxy/configure-logging-and-tracing.md): Choose which request and response data an A2A Proxy reports, and turn on OpenTelemetry tracing.
