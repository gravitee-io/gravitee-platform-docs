# Operations

The Operations group of an A2A Proxy controls which gateway instances load it, and keeps the record of every version it has run.

* [**Configure A2A Proxy deployment**](../../configure-a2a-proxy-deployment.md): Choose which gateway instances load an A2A Proxy by assigning sharding tags.
* [**Review A2A Proxy deployment history**](../../review-a2a-proxy-deployment-history.md): Inspect or compare versions of an A2A Proxy, and roll back to an earlier API definition.
