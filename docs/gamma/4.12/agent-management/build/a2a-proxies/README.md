# A2A Proxies

An A2A Proxy exposes an upstream agent behind the AI Gateway so other agents can discover and call it. These guides follow the groups of the A2A Proxy sidebar in the Gamma console.

* [**Expose your agent with the A2A Proxy**](../expose-agent-with-a2a-proxy.md): Expose an upstream agent behind the AI Gateway so other agents can discover and call it.
* [**Configure your A2A Proxy**](../configure-your-a2a-proxy/README.md): Configure an A2A Proxy's behavior, security, and observability from the Gamma console.
* [**Add policies to your A2A Proxy**](../configure-your-a2a-proxy/add-policies-to-a2a-proxy.md): Add policies in the Policy Studio to secure agent-to-agent traffic and control its behavior.
* [**Publish your agent to the Developer Portal**](../../publish/publish-your-agent-to-the-developer-portal.md): List the agent in the Developer Portal catalog so consumers can find it and subscribe.
