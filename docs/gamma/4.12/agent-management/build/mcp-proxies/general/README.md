# General

The General group of an MCP Proxy holds its settings, its connection to the upstream server, and its notifications.

* [**Configure your MCP proxy**](../../configure-your-mcp/README.md): Configure upstream authentication so the Gateway injects the credentials a third-party MCP server needs.
* [**Configure MCP Proxy notifications**](../../configure-mcp-proxy-notifications.md): Choose which API events send notifications for an MCP Proxy and where they are delivered.
