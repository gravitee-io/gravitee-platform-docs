# Operations

The Operations group of an MCP Proxy controls which gateway instances load it, and keeps the record of every version it has run.

* [**Configure MCP Proxy deployment**](../../configure-mcp-proxy-deployment.md): Choose which gateway instances load an MCP Proxy by assigning sharding tags.
* [**Review MCP Proxy deployment history**](../../review-mcp-proxy-deployment-history.md): Inspect or compare versions of an MCP Proxy, and roll back to an earlier API definition.
