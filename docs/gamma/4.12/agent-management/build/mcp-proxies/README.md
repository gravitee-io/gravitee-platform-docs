# MCP Proxies

An MCP Proxy governs an upstream MCP server with authentication, authorization, and observability. These guides follow the groups of the MCP Proxy sidebar in the Gamma console.

* [**Create an MCP proxy**](../create-an-mcp-proxy.md): Create an MCP Proxy that governs an upstream MCP server with authentication, authorization, and observability.
* [**Create an MCP Studio**](../create-an-mcp-studio.md): Compose tools, resources, and prompts from multiple sources into a governed Composite MCP Server.
* [**Configure your MCP proxy**](../configure-your-mcp/README.md): Configure upstream authentication so the Gateway injects the credentials a third-party MCP server needs.
* [**Design**](design/README.md): Apply policies at the server, method, and tool level, and edit what an MCP Studio exposes.
* [**Manage subscriptions**](../../publish/manage-subscriptions.md): Subscribe an application to a plan, approve the request, and find the credential the AI Gateway checks.
* [**Connect and secure the GitHub MCP server**](../configure-your-mcp/connect-and-secure-github-mcp-server.md): Connect GitHub's MCP server to Gravitee and curate the tools it exposes.
* [**Connect and secure the Atlassian MCP server**](../configure-your-mcp/connect-and-secure-atlassian-mcp-server.md): Connect Atlassian's MCP server to Gravitee and curate the tools it exposes.
* [**Connect and secure the Stripe MCP server**](../configure-your-mcp/connect-and-secure-stripe-mcp-server.md): Connect Stripe's MCP server to Gravitee and withhold the tool you do not want exposed.
