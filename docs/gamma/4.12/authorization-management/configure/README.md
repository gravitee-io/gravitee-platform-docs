# Manage policies

The **Policy Management** group of the Authorization Management sidebar holds the **MCPs**, **AI Models**, **APIs**, **A2A Agents**, and **Custom Policies** pages.

* [**Create, update, and delete policies**](create-update-delete-policies.md). Reference for the Authorization Management policy editor, covering how to create, name, build, deploy, and delete a policy.
* [**MCP policy examples**](mcp-policy-examples.md). Govern MCP servers, tools, and prompts with policy examples for group access, time windows, and device trust.
* [**AI policy example**](ai-policy-example.md). Control which teams reach which AI models with policy examples for token budgets, cost ceilings, and guardrails.
* [**API policy examples**](api-policy-examples.md). Govern API proxies, endpoints, and data fields with policy examples for scopes, rate limits, and tenant isolation.
* [**Custom policies**](custom-policies/README.md). Custom policies govern resources outside the MCP, API, Agent, AI Model, and Event categories.
