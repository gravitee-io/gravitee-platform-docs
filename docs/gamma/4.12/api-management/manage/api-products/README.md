# API Products

An API Product has its own sidebar. Its groups are **General**, **Consumer Access**, **Security**, and **Operations**.

* [**Create API Products**](../../build/api-products.md). API Products bundle multiple API proxies into one consumer-facing product with shared plans.
* [**Configure API products**](../../build/configure-your-api-product/README.md). Attach APIs, create plans, manage consumers and team access, and choose where an API Product deploys.
* [**General**](general/README.md). Holds the **Overview**, **General**, and **APIs** pages.
* [**Security**](security/README.md). Holds the **User Permissions** pages.
* [**Operate**](operations/README.md). Holds the Operate pages.
* [**Manage API products with the Management API**](../../build/configure-your-api-product/manage-api-products-with-the-management-api.md). Create an API product, attach APIs, add and publish plans, and deploy it over the v2 Management API.
* [**API product configuration reference**](../../build/configure-your-api-product/api-product-configuration-reference.md). Every API product property, the flag that decides which APIs can be bundled, and the plan types a product supports.
