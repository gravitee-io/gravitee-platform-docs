The **Operations** group of an API Product's sidebar holds the **Deployment** pages.

* [**Configure product deployment**](../../../build/configure-your-api-product/configure-product-deployment.md). Assign sharding tags to an API Product so only the API Gateway instances that advertise a matching tag load it.
