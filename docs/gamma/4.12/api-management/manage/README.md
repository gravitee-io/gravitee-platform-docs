# Manage

The **Manage** group of the API Management sidebar holds the **API Proxies** and **API Products** pages.

* [**API Proxies**](api-proxies/README.md). Create an API proxy, then configure it from the groups of its own sidebar.
* [**API Products**](api-products/README.md). Create an API Product, then configure it from the groups of its own sidebar.
