# Consumer Access

The **Consumer Access** group of an API proxy's sidebar holds the **Plans**, **Consumers**, and **Broadcasts** pages.

* [**Secure your API proxy**](../../../build/secure-your-api-proxy.md). Attach a Keyless, API Key, JWT, OAuth2, or mTLS plan to control how consumers authenticate to an API proxy.
* [**Establish consumer access**](../../../build/configure-your-api-proxy/establish-consumer-access.md). Applications, subscriptions, and API keys control how consumers discover and authenticate with your API.
* [**Broadcast messages to consumers**](../../../build/configure-your-api-proxy/broadcast-messages-to-consumers.md). Send a one-way announcement to the consumers of an API proxy about a change, an update, or a maintenance window.
