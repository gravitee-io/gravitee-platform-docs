# API Proxies

An API proxy has its own sidebar. Its groups are **General**, **Gateway**, **Design**, **Consumer Access**, **Security**, **Monitoring**, and **Operations**.

* [**Create an API proxy**](../../build/create-an-api-proxy.md). Create an API proxy in the Gamma console with the from-scratch wizard or a quick-start template.
* [**Configure your API proxy**](../../build/configure-your-api-proxy/README.md). Refine an API proxy from the detail workspace, which groups configuration into seven sidebar sections.
* [**General**](general/README.md). Holds the **Overview**, **General**, **API Properties**, **Resources**, **Notifications**, **API Score**, **Response Templates**, and **CORS** pages.
* [**Gateway**](gateway/README.md). Holds the **Entrypoints**, **Endpoints**, **Failover**, **Health Check Dashboard**, and **Reporter Settings** pages.
* [**Design**](design/README.md). Holds the **Policy Studio** pages.
* [**Consumer Access**](consumer-access/README.md). Holds the **Plans**, **Consumers**, and **Broadcasts** pages.
* [**Security**](security/README.md). Holds the **Authorization** and **User Permissions** pages.
* [**Monitor**](monitoring/README.md). Holds the Monitor pages.
* [**Operate**](operations/README.md). Holds the Operate pages.
