# Operate

The **Operations** group of an API proxy's sidebar holds the **Deployment** pages.

* [**Configure deployment**](../../../build/configure-your-api-proxy/configure-deployment.md). Choose which API Gateway instances load an API definition by assigning sharding tags.
* [**Review deployment history**](../../../build/configure-your-api-proxy/review-deployment-history.md). Compare two deployed versions of an API definition and roll back to an earlier one.
