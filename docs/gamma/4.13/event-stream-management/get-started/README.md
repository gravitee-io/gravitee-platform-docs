# Get started

New to Event Stream Management in Gamma? Start with the following pages:

* [**Event Stream Management overview**](event-stream-management-overview.md). This page explains what Event Stream Management does and how it fits into the Gamma platform.
* [**Register your first cluster**](register-your-first-cluster.md). This quickstart shows you how to register and deploy a Kafka cluster in Gamma, the foundation for Virtual Clusters and for Kafka Services that bind to a registered cluster.
* [**Create your first Kafka Service**](create-your-first-kafka-service.md). This quickstart shows you how to create a Kafka Service in the Gamma console and start it on the Event Gateway.
* [**Create your first Virtual Cluster**](create-your-first-virtual-cluster.md). This quickstart shows you how to put the connections of your registered clusters behind a single endpoint.

Once you're in the module, the [Overview page](../general/use-the-overview-page.md) counts what the environment holds and links to every area.
