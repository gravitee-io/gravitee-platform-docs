# Kafka Infrastructure

The **Kafka Infrastructure** group of the Event Stream Management sidebar holds the **Clusters**, **Virtual Clusters**, and **Explorer** pages.

* [**Register your Kafka clusters**](clusters/register-your-kafka-clusters.md). Register an existing Kafka cluster with Gamma so Kafka Services and Virtual Clusters can be built on it.
* [**Manage clusters**](clusters/manage-a-cluster.md). Find, edit, deploy, undeploy, and delete Clusters, and see which Kafka Services use each one.
* [**Manage cluster permissions**](clusters/manage-cluster-permissions.md). Decide who can manage a Cluster or a Virtual Cluster.
* [**Virtual Clusters**](virtual-clusters/README.md). Present one or more Cluster connections to clients as a single Kafka cluster.
* [**Kafka Explorer**](kafka-explorer/README.md). Read the live brokers, topics, consumer groups, and messages of a Kafka target through a saved connection.
