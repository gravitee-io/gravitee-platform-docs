# Virtual Clusters

A Virtual Cluster composes one or more registered clusters into a single logical Kafka environment. The **Virtual Clusters** item of the **Kafka Infrastructure** group lists them, and a Kafka Service can expose one instead of a registered cluster.

* [**Virtual Clusters overview**](kafka-virtual-clusters-overview.md). Key concepts, Kafka Mesh, consumer groups, and protocol support.
* [**Establish a Virtual Cluster**](establish-a-virtual-cluster.md). Create a Virtual Cluster from your registered clusters.
* [**Virtual Cluster runtime behavior reference**](kafka-virtual-cluster-runtime-behavior-reference.md). Deploy, update, and manage Virtual Clusters, with detailed operation-level behavior.
