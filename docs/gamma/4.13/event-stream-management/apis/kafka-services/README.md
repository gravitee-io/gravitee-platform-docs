# Kafka Services

A Kafka Service is a native Kafka API. Kafka clients connect to it with the Kafka protocol, and the Event Gateway forwards their requests to a registered cluster or to a Virtual Cluster. The **Kafka Services** item of the **APIs** group lists them.

* [**Create a Kafka service with a registered cluster**](create-a-kafka-service-with-a-registered-cluster.md). Govern a registered Kafka cluster directly.
* [**Create a Kafka service with a Virtual Cluster**](create-a-kafka-service-with-a-virtual-cluster.md). Govern a logically isolated environment built on one or more clusters.
* [**Duplicate a Kafka service**](duplicate-a-kafka-service.md). Create a copy of an existing Kafka Service with a new listener host prefix.
