# Manage

The **Manage** group of the Event Stream Management sidebar holds **Clusters** and **Kafka Explorer**.

* [**Kafka Explorer**](kafka-explorer/README.md). Read the live brokers, topics, consumer groups, and messages of a Kafka target through a saved connection.

**Clusters** is covered under **Import**, because registering a cluster is how one appears there. See [Register your Kafka clusters](../import/register-your-kafka-clusters.md).
