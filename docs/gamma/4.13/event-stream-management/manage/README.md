# Manage

The **Manage** group of the Event Stream Management sidebar holds the **Clusters** and **Kafka Explorer** pages.

* [**Register your Kafka clusters**](../import/register-your-kafka-clusters.md). Register an existing Kafka cluster with Gamma so Kafka Services and Virtual Clusters can be built on it.
* [**Kafka Explorer**](kafka-explorer/README.md). Kafka Explorer reads the live brokers, topics, consumer groups, and messages of a Kafka target through a saved connection.
