# General

The **General** group of the Event Stream Management sidebar holds the **Overview** page. The Overview page is also where Event Stream Management opens.

* [**Use the Overview page**](use-the-overview-page.md). See how many Kafka Services, Message APIs, Clusters, Virtual Clusters, and Kafka Explorer connections the environment holds, and create, import, or open each of them from one page.

The other groups of the sidebar are documented in their own sections:

* [**APIs**](../apis/README.md). Kafka Services and Message APIs.
* [**Kafka Infrastructure**](../kafka-infrastructure/README.md). Clusters, Virtual Clusters, and the Kafka Explorer.
* [**Observability**](../observability/README.md). Dashboards, Logs, and Tracing, plus API Score when the environment enables it.
