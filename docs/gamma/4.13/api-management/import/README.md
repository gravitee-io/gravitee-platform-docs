# Import

Import APIs that already exist elsewhere into API Management. Where the source is another gateway, the migration is a conversion rather than a copy, so it is treated as its own body of work.

The following pages cover a gateway migration:

* [**Migrate from another gateway**](migrate-from-another-gateway.md). How the migration method works, what it refuses to convert, and how to scope a MuleSoft migration.
* [**Migrate an API estate to Gravitee**](migrate-an-api-estate-to-gravitee.md). The full procedure, from inventory through to reconciling both gateways.
* [**Source gateway reference**](source-gateway-reference.md). Management API paths, Expression Language syntax, where each gateway holds behavior, credential export, and tested coverage.

To import a single API from an OpenAPI definition rather than a whole estate, see [Import an API proxy](../build/import-an-api-proxy.md).
