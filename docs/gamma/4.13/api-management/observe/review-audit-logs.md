# Review audit logs

The **Audit Logs** page gathers the events and changes generated by API Management for this API, so you trace who changed what, and when.

To open the page, follow these steps:

1. Click **API Proxies** in the module sidebar.
2. Select your API proxy.
3. Click **Audit Logs** in the API proxy sidebar.

## Read the audit trail

The table lists each audit event's **Date**, **Actor**, **Event**, and **Target** columns. When an event recorded a configuration change, its row carries the **View patch** action, which opens the **JSON Patch** panel showing the exact change.

## Filter the events

The toolbar filters the audit trail:

* The event type filter lists every event type recorded for this API, plus **All events**.
* The **Date range** picker restricts the results to a period.
* **Reset** clears the active filters. With filters active and no matches, the table reads **No audit logs found**.

## Verification

To verify the audit trail is working as expected, follow these steps:

1. Change a setting of the API, for example its description, and save.
2. Open the **Audit Logs** page. The change appears with your user as the **Actor**.
3. Click **View patch** on the row. The **JSON Patch** panel shows the changed field.
