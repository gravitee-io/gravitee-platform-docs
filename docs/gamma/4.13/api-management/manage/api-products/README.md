# API Products

An API Product bundles several API proxies into one consumer-facing offering with shared plans. The **API Products** page in the API Management module is where you create and open one.

* [**Create an API Product**](../../build/api-products.md). When to use a product, and how to create one.
* [**Manage product APIs**](../../build/configure-your-api-product/manage-product-apis.md). Attach and detach API proxies.
* [**Manage members and ownership**](../../build/configure-your-api-product/manage-members-and-ownership.md). Members, groups, roles, and ownership.
* [**Configure product deployment**](../../build/configure-your-api-product/configure-product-deployment.md). The sharding tags that select Gateway instances.
* [**Manage API Products with the Management API**](../../build/configure-your-api-product/manage-api-products-with-the-management-api.md). The full lifecycle over the v2 Management API.
* [**API Product configuration reference**](../../build/configure-your-api-product/api-product-configuration-reference.md). Every product property and the plan types a product supports.
