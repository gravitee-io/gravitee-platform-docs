# General

The **General** group of an API Product's sidebar holds the **Overview**, **Settings**, **User Permissions**, and **APIs** pages.

* [**Manage members and ownership**](../../../build/configure-your-api-product/manage-members-and-ownership.md). Add members, attach groups, change roles, and transfer ownership of an API product.
* [**Manage product APIs**](../../../build/configure-your-api-product/manage-product-apis.md). Attach and detach API proxies from an API Product so subscribers reach every API it bundles.
