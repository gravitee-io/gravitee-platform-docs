# Design

The **Design** section of an API proxy covers what the proxy does with a request once it arrives. It holds the paths the proxy answers on, the policies it runs, the backends it calls, and the payloads it returns.

* [**Configure response templates**](../../../build/configure-your-api-proxy/configure-response-templates.md). The status, headers, and body the gateway returns in place of a default error payload.

The section's other items are documented under the sections they were first written for. **Entrypoints**, **Endpoints**, and **Failover** are in [Gateway](../gateway/README.md), **Policy Studio** has [its own section](../policy-studio/README.md), and **Resources**, **API Properties**, and **CORS** are in [General](../general/README.md).
