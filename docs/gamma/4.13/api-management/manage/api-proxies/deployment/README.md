# Deployment

The **Operations** section of an API proxy decides which API Gateway instances run it, and records every version that has been deployed.

* [**Configure deployment**](../../../build/configure-your-api-proxy/configure-deployment.md). The sharding tags that select Gateway instances.
* [**Review deployment history**](../../../build/configure-your-api-proxy/review-deployment-history.md). Compare deployed versions and roll back.
