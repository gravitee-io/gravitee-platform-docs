# Monitor

The **Monitoring** group of an API proxy's sidebar holds the **Notifications**, **Alerts**, **Audit Logs**, and **Health Check Dashboard** pages.

* [**Configure notifications**](../../../build/configure-your-api-proxy/configure-notifications.md). Send console, email, or webhook alerts when API events occur, such as a deployment or a subscription change.
* [**Review audit logs**](../../../observe/review-audit-logs.md). Trace who changed what, and when, on an API proxy with its audit trail.
* [**Monitor endpoint health**](../../../observe/monitor-endpoint-health.md). Track backend endpoint availability, response times, and failed health checks for an API.
