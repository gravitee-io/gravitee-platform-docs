# Consumer access

The **Consumer Access** section of an API proxy controls how consumers authenticate to it, subscribe to it, and hear from you about it.

* [**Secure your API proxy**](../../../build/secure-your-api-proxy.md). The security plan consumers authenticate against.
* [**Establish consumer access**](../../../build/configure-your-api-proxy/establish-consumer-access.md). Applications, subscriptions, and approvals.
* [**Broadcast messages to consumers**](../../../build/configure-your-api-proxy/broadcast-messages-to-consumers.md). One-way announcements to your consumers.
