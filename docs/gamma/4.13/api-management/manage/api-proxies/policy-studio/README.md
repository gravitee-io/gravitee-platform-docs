# Policy Studio

The **Policy Studio** is the Design section of an API proxy, where you build the policy flows the API Gateway runs on every request and response.

* [**Control how policy flows are matched to requests**](../../../build/configure-your-api-proxy/configure-flow-execution.md). The flow execution mode.
* [**Reuse policies with shared policy groups**](../../../build/shared-policy-groups.md). Attach a reusable set of policies to a flow.
* [**Apply security policies**](../../../build/configure-your-api-proxy/apply-security-policies.md). How the policy chain runs, and the common policy types.
