# Gateway

The **Gateway** section of an API proxy covers how traffic reaches the proxy, where the proxy sends it, and what the proxy reports about it.

* [**Configure entrypoints**](../../../build/configure-your-api-proxy/configure-entrypoints.md). The paths consumers use to reach the proxy.
* [**Configure endpoints**](../../../build/configure-your-api-proxy/configure-backend-security.md). Endpoint groups, load balancing, and TLS.
* [**Configure failover**](../../../build/configure-your-api-proxy/configure-failover.md). Retries and the circuit breaker.
* [**Configure logging and tracing**](../../../build/configure-your-api-proxy/configure-logging-and-tracing.md). What the proxy reports to logs and analytics.
