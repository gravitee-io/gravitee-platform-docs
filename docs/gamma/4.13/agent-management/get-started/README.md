# Get started

New to Agent Management in Gamma? Start with the following pages:

* [**Roles and permissions**](roles-and-permissions.md). This page lists the environment-scoped permissions that govern who can view, create, edit, and delete Agent Management resources.
* [**Create your first MCP server**](create-your-first-mcp-server.md). In this quickstart, you configure an MCP Proxy in front of an upstream MCP server, and then verify tool invocations through the AI Gateway.
* [**Create your first LLM Proxy**](create-your-llm-proxy.md). In this quickstart, you configure an LLM Proxy, connect it to a model provider, and then send a test prompt.
* [**Configure your Access Management instance**](../build/configure-your-access-management-instance.md). Connect the module to Gravitee Access Management, select an environment and domain, and check that the domain has the capabilities agent identities rely on.

For what Agent Management does and how it fits the platform, see [Agent Management overview](ai-management-overview.md).
