# Integrations

Integrations bring entities from outside Gamma into the Catalog. Model integrations connect an upstream AI platform and import the models it offers, and agents are imported from the same connected integrations. Agents also arrive without anyone connecting a platform: Edge Management's shadow AI detections become Catalog entries on their own schedule.

* [**Connect integrations**](../connect-integrations.md). Link Gamma to upstream providers so their AI models and agents sync into the Catalog.
* [**Import an agent from an integration**](../import-an-agent.md). Import A2A agents and hyperscaler-federated agents from connected integrations.
* [**Discover shadow AI agents from Edge Management**](../discover-shadow-ai-agents-from-edge-management.md). Turn the AI provider domains Edge Management detects into shadow AI agents in the Catalog, and read which processes and devices reached each one.
