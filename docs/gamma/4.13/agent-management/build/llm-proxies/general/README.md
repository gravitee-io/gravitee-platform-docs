# General

The General group of an LLM Proxy holds its settings, its cross-origin access, and its notifications.

* [**Configure LLM Proxy CORS**](../../configure-llm-proxy-cors.md). Let browser-based clients on other origins call the proxy by setting the allowed origins, methods, and headers.
* [**Configure LLM Proxy notifications**](../../configure-llm-proxy-notifications.md). Choose which API events send notifications for an LLM Proxy and where they are delivered.
