# General

The **General** group of an MCP Proxy holds its **Overview**, **Settings**, **User Permissions**, and **Metadata** pages. The shared [Manage user permissions for your proxies](../../manage-user-permissions-for-your-proxies.md) guide covers the **User Permissions** page, and the shared [Manage metadata for your proxies](../../manage-metadata-for-your-proxies.md) guide covers the **Metadata** page.
