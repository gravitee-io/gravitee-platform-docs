# Design

The **Design** group of an MCP Proxy holds its **Entrypoint**, **Policy Studio**, **Endpoint**, **Resources**, **API Properties**, and **CORS** pages. An MCP Studio shows **Tools** in place of **Endpoint**.

* [**Configure MCP specification versions**](../../configure-your-mcp/configure-mcp-specification-versions.md). Choose the MCP specification versions clients may connect with, and the versions the gateway uses with the upstream server.
* [**Add policies to your MCP server**](../../configure-your-mcp/add-policies-to-mcp-server.md). Control which consumers can invoke which tools with fine-grained authorization policies.
* [**Exchange tokens for upstream MCP servers**](../../configure-your-mcp/exchange-tokens-for-upstream-mcp-servers.md). Call the upstream MCP server with a token exchanged for the consumer's token.
