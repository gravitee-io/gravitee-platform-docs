# Design

The **Design** group of an MCP Proxy holds its **Entrypoint**, **Policy Studio**, **Endpoint**, **Resources**, **API Properties**, and **CORS** pages. An MCP Studio shows **Tools** in place of **Endpoint**. The shared [Configure resources for your proxies](../../configure-resources-for-your-proxies.md) and [Configure properties for your proxies](../../configure-properties-for-your-proxies.md) guides cover the **Resources** and **API Properties** pages.

* [**Configure the MCP Proxy entrypoint**](../../configure-mcp-proxy-entrypoint.md). Change the context path that MCP clients call, and copy the URL it gives.
* [**Add policies to your MCP server**](../../configure-your-mcp/add-policies-to-mcp-server.md). Control which consumers can invoke which tools with fine-grained authorization policies.
* [**Exchange tokens for upstream MCP servers**](../../configure-your-mcp/exchange-tokens-for-upstream-mcp-servers.md). Call the upstream MCP server with a token exchanged for the consumer's token.
* [**Configure the MCP Proxy endpoint**](../../configure-mcp-proxy-endpoint.md). Change the upstream MCP server and how the gateway connects to it.
* [**Configure MCP Proxy CORS**](../../configure-mcp-proxy-cors.md). Let MCP clients running in a browser call the proxy from another origin.
