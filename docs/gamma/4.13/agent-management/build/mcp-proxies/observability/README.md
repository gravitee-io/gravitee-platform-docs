# Observe

The **Observability** group of an MCP Proxy holds its **Dashboard**, **Logs**, and **Tracing** links. Each one opens a page of the Agent Management **Observability** group in a new tab, and **Dashboard** and **Logs** open filtered to the proxy. For those pages, see [Observe](../../../observe/README.md).
