# Design

The Design group of an A2A Proxy holds the Policy Studio, where the policies that govern agent-to-agent traffic are applied. It also holds the response templates that override the errors the AI Gateway returns.

* [**Add policies to your A2A Proxy**](../../configure-your-a2a-proxy/add-policies-to-a2a-proxy.md). Add policies in the Policy Studio to secure agent-to-agent traffic and control its behavior.
* [**Configure A2A Proxy response templates**](../../configure-your-a2a-proxy/configure-a2a-proxy-response-templates.md). Replace the AI Gateway's default error payload for one error and one kind of client.
