# Consumer access

Open an A2A Proxy to the consumers you choose, then manage their subscription requests through the lifecycle.

* [**Manage A2A Proxy plans**](../../configure-your-a2a-proxy/manage-a2a-proxy-plans.md). Create, publish, and close the plans that control how consumers authenticate to the proxy.
* [**Manage subscriptions**](../../../publish/manage-subscriptions.md). Subscribe an application to a plan, approve the request, and find the credential the AI Gateway checks.
