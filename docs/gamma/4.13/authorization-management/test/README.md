# Test

The **Testing** group of the Authorization Management sidebar holds the **Policy Simulator** and **Access Explorer** pages.

* [**Simulate policy decisions**](simulate-policy-decisions.md). Check which principals your MCP policies permit to call which MCP tools, before you deploy the policies.
* [**Explore a principal's access**](explore-a-principals-access.md). List the MCP tools that one principal is permitted to call, grouped by MCP server.
