# Directories

The **Directories** group of the Authorization Management sidebar holds the **SCIM Directories** and **All sync activity** pages.

* [**Sync principals from a SCIM directory**](sync-principals-from-a-scim-directory.md). Connect a SCIM 2.0 directory and import its users and groups as principals, by hand or on a schedule.
* [**Review SCIM sync runs**](review-scim-sync-runs.md). Check what each sync imported and changed, and why a record was left out.
