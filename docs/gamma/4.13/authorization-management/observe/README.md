# Observe

The **Observability** group of the Authorization Management sidebar holds the **Dashboards** and **Decisions** pages.

* [**Monitor authorization decisions**](monitor-authorization-decisions.md). Read the **Authorization — Overview** dashboard: how many decisions there were, what was forbidden, where no policy applied, and how long evaluation took.
* [**Review authorization decisions**](review-authorization-decisions.md). List the decisions one by one, filter them, and open one to see the policies and reasons behind it.
