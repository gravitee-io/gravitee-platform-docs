# Assets

The **Assets** group of the **Organization** section holds the **Tenants** and **Entrypoints & Sharding Tags** pages.

* [**Manage tenants**](../../manage-tenants.md). Create, edit, and delete tenants, apply a tenant to a gateway, and assign one to an API endpoint.
* [**Manage entrypoints and sharding tags**](../../manage-entrypoints-and-sharding-tags.md). Configure the default entrypoint values, and manage sharding tags and entrypoint mappings.
