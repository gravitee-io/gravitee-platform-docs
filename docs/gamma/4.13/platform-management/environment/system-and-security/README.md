# System & Security

The **System & Security** group of the **Environment** section holds the **Access Management**, **Gateways**, **Alerts**, **Notifications**, **API Health Check**, **SMTP**, **Security Plan Types**, and **Audit** pages.

* [**Configure Access Management**](../../configure-access-management.md). Connect the Gamma console to a Gravitee Access Management instance.
* [**Monitor gateway instances**](../../monitor-gateway-instances.md). Read the status of a gateway instance, view its details, and monitor its health metrics.
* [**Configure environment alerts**](../../configure-environment-alerts.md). Create, edit, and delete alerts, and track their activity and history.
* [**Configure Security Plan Types**](../../configure-security-plan-types.md). Change which plan security types are available to the APIs of the environment.

The environment audit trail is covered on [Review organization and environment audit logs](../../review-audit-logs.md).
