# Publish your API

## Overview

This guide explains how to Publish your API.

## Prerequisites

* Complete the steps in [create-an-api.md](create-an-api.md "mention").
* Complete the steps in [add-security.md](add-security.md "mention").
* Complete the steps in [add-a-policy.md](add-a-policy.md "mention").

## Publish your API

{% hint style="info" %}
This page applies to the Classic Portal. The New Developer Portal doesn't use the API's published state. To make an API visible in the New Developer Portal, add the API to the portal navigation and publish it there. For more information, see [Manage Portal Navigation and APIs](../../developer-portal/new-developer-portal/customize-the-navigation/README.md).
{% endhint %}

1.  From the dashboard, click **APIs**.

    <figure><img src="../../.gitbook/assets/A55EF9D7-6D61-4D8F-8BA1-F71122515FAA.jpeg" alt="The console dashboard with APIs highlighted in the left navigation, showing one API and one application."><figcaption></figcaption></figure>
2.  Click the API that you created in [create-an-api.md](create-an-api.md "mention").

    <figure><img src="../../.gitbook/assets/gs-first-api-publish-your-api-65.png" alt="The APIs list with the Gateways item highlighted in the left navigation, showing one API with its definition, status, and context path."><figcaption></figcaption></figure>
3.  In the **Danger Zone** section, click **Publish the API**.

    <figure><img src="../../.gitbook/assets/CD257AC3-4FE5-4277-AF15-65EF394D9979.jpeg" alt="The Configuration page of an API with the Publish the API action highlighted in the Danger Zone."><figcaption></figcaption></figure>
4.  In the **Publish API** pop-up window, click **Publish**. Your API is now published to the Developer Portal.

    <figure><img src="../../.gitbook/assets/getting-started-create-and-publish-your-40-1.png" alt="The Configuration page of an API with the Publish API confirmation dialog open, asking whether to publish, above the Danger Zone."><figcaption></figcaption></figure>

## Verification

Your API appears on the Developer Portal. To view your API in the Developer Portal, complete the following steps:

1.  In the console header navigation, click **Developer Portal**.

    <figure><img src="../../.gitbook/assets/6B137E7B-B69B-4EFA-9099-B5FA1496B0D7.jpeg" alt="The Configuration page of a published API with the Developer Portal link highlighted in the top bar, showing Unpublish the API in the Danger Zone."><figcaption></figcaption></figure>
2.  In the Developer Portal, click **Explore APIs**.

    <figure><img src="../../.gitbook/assets/gs-first-api-publish-your-api-66.png" alt="The developer portal home page, with a dark header, a headline, an API search box, and an Explore APIs button."><figcaption></figcaption></figure>
3.  In the **Catalog** page, click **All APIs.**

    <figure><img src="../../.gitbook/assets/69CA0019-F818-42A2-9790-8C51B0E34863.jpeg" alt="The developer portal Catalog with the All APIs tab highlighted, showing an empty categories view."><figcaption></figcaption></figure>

Your API appears in the **All APIs** section.

<figure><img src="../../.gitbook/assets/gs-first-api-publish-your-api-67.png" alt="The All APIs tab of the developer portal catalogue, showing one API card with its logo, owner, subscriber count, and a View API button."><figcaption></figcaption></figure>
