# Add API Documentation

## Overview

This guide explains how to add documentation to your first API.

## Prerequisites

* Complete the steps in [create-an-api.md](create-an-api.md "mention").
* Complete the steps in [add-security.md](add-security.md "mention").
* Complete the steps in [add-a-policy.md](add-a-policy.md "mention").

## Add API documentation

1.  From the dashboard, click **APIs**.

    <figure><img src="../../.gitbook/assets/6DD0E65F-0096-4CD0-A5E4-ADFC9815CCB2.jpeg" alt="The console dashboard for a production environment with APIs highlighted in the left navigation, showing no APIs or applications yet."><figcaption></figcaption></figure>
2.  Click the API that you created in [create-an-api.md](create-an-api.md "mention").

    <figure><img src="../../.gitbook/assets/gs-first-api-add-api-documentation-326.png" alt="The APIs list filtered by a saved search, with APIs highlighted in the left navigation and one API listed."><figcaption></figcaption></figure>
3.  In your API menu, click **Documentation**.\
    \\

    <figure><img src="../../.gitbook/assets/7405FAE3-1497-40D0-A658-664B364E8493.jpeg" alt="The Configuration page of an API with Documentation highlighted in the API menu, showing the general settings above a Danger Zone."><figcaption></figcaption></figure>
4.  Click **Documentation Pages**, and then click **Add new page**.

    <figure><img src="../../.gitbook/assets/gs-first-api-add-api-documentation-327.png" alt="The Documentation Pages tab of an API, empty, with Add new folder and Add new page buttons."><figcaption></figcaption></figure>
5.  From the **Add new page** dropdown menu, click Markdown.

    <figure><img src="../../.gitbook/assets/gs-first-api-add-api-documentation-328.png" alt="The Documentation Pages tab with the Add new page menu open, offering Markdown, OpenAPI, AsyncAPI, and AsciiDoc."><figcaption></figcaption></figure>
6. In the **Name** field, type the name of your documentation page. For example, My first page.
7.  In the **Visibility** section, Click **Public**, and then click **Next**.

    <figure><img src="../../.gitbook/assets/gs-first-api-add-api-documentation-329.png" alt="The Configure page step of the documentation page wizard, with a page name entered and Public visibility selected over Private."><figcaption></figcaption></figure>
8.  In the Determine source page, click **Next**.

    <figure><img src="../../.gitbook/assets/gs-first-api-add-api-documentation-330.png" alt=""><figcaption></figcaption></figure>
9. In the **Page content** section, add the documentation for your API using Markdown.
10. Click **Save and publish**.

    <figure><img src="../../.gitbook/assets/gs-first-api-add-api-documentation-331.png" alt=""><figcaption></figcaption></figure>

## Verification

Your document page appears in the **Documentation pages** tab of the **Documentation** screen.

<figure><img src="../../.gitbook/assets/gs-first-api-add-api-documentation-332.png" alt=""><figcaption></figcaption></figure>

## Next steps

Publish your API. For more information about publishing your API, see [publish-your-api.md](publish-your-api.md "mention").
