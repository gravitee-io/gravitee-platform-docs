# Consume your LLM proxy with LangChain

## Overview

This guide explains how to consume an LLM proxy from a LangChain application.

A LangChain chain calls its model provider directly by default, which means the process running the chain holds a provider credential and every prompt reaches the provider unscreened. Routing the chain through an LLM proxy moves the provider credential into the Gateway and lets you apply Gravitee policies to the traffic.

The LLM proxy exposes an OpenAI-compatible API, so LangChain's OpenAI integration can call it without a custom adapter. The chain authenticates to the Gateway with its own credential and requests a model by the alias configured on the LLM proxy, so it never names a provider or a provider model.

## Prerequisites

Before you begin, confirm that you have the following:

* A fully Self-Hosted Installation of APIM or a Hybrid Installation of APIM. For more information about installing APIM, see [self-hosted-installation-guides](../../self-hosted-installation-guides/ "mention") and [hybrid-installation-and-configuration-guides](../../hybrid-installation-and-configuration-guides/ "mention").
* An Enterprise License. For more information about obtaining an Enterprise license, see [enterprise-edition.md](../../introduction/enterprise-edition.md "mention").
* A completed LLM proxy. For more information, see [proxy-your-llms.md](proxy-your-llms.md "mention").
* An API key plan published on your LLM proxy, and an active subscription to that plan.
* The LangChain OpenAI integration package installed in your application environment. For more information about installing LangChain packages, go to the [LangChain documentation](https://python.langchain.com/docs/introduction/).

## Connect LangChain to your LLM proxy

1. In your application, import the `ChatOpenAI` chat model.
2.  Set `base_url` to your LLM proxy, and pass your Gravitee API key as a default header:<br>

    ```python
    from langchain_openai import ChatOpenAI

    llm = ChatOpenAI(
        base_url="https://<GATEWAY_URL>/<CONTEXT_PATH>",
        default_headers={"X-Gravitee-Api-Key": "YOUR_API_KEY_HERE"},
        model="YOUR_MODEL_ALIAS",
    )
    ```

    * Replace `<GATEWAY_URL>` with your Gateway URL.
    * Replace `<CONTEXT_PATH>` with the context path of your LLM proxy. For example, `llmtest`.
    * Replace `YOUR_API_KEY_HERE` with the API key from your subscription.
    * Replace `YOUR_MODEL_ALIAS` with an alias configured on your LLM proxy endpoint.
3.  Use the chat model in a chain as you would any other LangChain chat model:<br>

    ```python
    from langchain_core.output_parsers import StrOutputParser
    from langchain_core.prompts import ChatPromptTemplate

    prompt = ChatPromptTemplate.from_messages([("human", "{input}")])
    chain = prompt | llm | StrOutputParser()

    print(chain.invoke({"input": "Say OK"}))
    ```

{% hint style="info" %}
The `model` value is an alias that the LLM proxy resolves through its model registry. If your LLM proxy uses a prefix policy that requires prefixed model names, a plain alias doesn't resolve. To send a plain alias, set the model governance prefix policy to **Models and aliases do not require a prefix**.
{% endhint %}

## Verify the connection

1. Run your application.
2. Confirm that the chain returns the content generated by your LLM.
