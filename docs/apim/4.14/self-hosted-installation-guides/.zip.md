# Self-host with .ZIP

## Overview

This guide explains how to install Gravitee APIM using the `.zip` distribution. This installation method is suitable for environments where RPM packages are not supported or preferred.

{% hint style="warning" %}
This installation guide is for only development and quick start purposes. Do not use it for production environments. For more information about best practices for production environments, contact your Technical Account Manager.
{% endhint %}

## Prerequisites

Before you install APIM with `.zip` packages, complete the following steps:

* Download the `.zip` binaries from [Gravitee.io Downloads](https://download.gravitee.io/#graviteeio-apim/distributions/).
* Ensure your Gravitee API Management directory uses the following structure:
  * `bin/`: Start scripts
  * `config/`: Configuration files
  * `lib/`: Libraries

## Install Gravitee APIM with .ZIP

{% hint style="info" %}
The following example installs Gravitee APIM on Ubuntu 22.04.
{% endhint %}

1.  Install Java 25 using the following commands:

    ```bash
    sudo apt update
    sudo apt install openjdk-25-jdk -y
    java -version
    ```

    * The Gateway and the Management API require Java 25. The Console and the Developer Portal are static files and don't need Java.
2.  Install MongoDB using the following commands:

    ```bash
    # Import GPG Key
    curl -fsSL https://pgp.mongodb.com/server-8.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-8.0.gpg --dearmor

    # Create sources list
    echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-8.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/8.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-8.0.list

    # Update and install
    sudo apt update
    sudo apt install -y mongodb-org

    # Enable and start
    sudo systemctl daemon-reload
    sudo systemctl enable mongod
    sudo systemctl start mongod

    # Verify
    sudo ss -lntp "( sport = 27017 )"
    ```
3.  Install Elasticsearch using the following commands:

    ```bash
    # Import GPG Key
    wget -qO - https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo gpg --dearmor -o /usr/share/keyrings/elasticsearch-keyring.gpg

    # Add repository
    echo "deb [signed-by=/usr/share/keyrings/elasticsearch-keyring.gpg] https://artifacts.elastic.co/packages/8.x/apt stable main" | sudo tee /etc/apt/sources.list.d/elastic-8.x.list

    # Update and install
    sudo apt update
    sudo apt install elasticsearch -y

    # Enable and start
    sudo systemctl daemon-reload
    sudo systemctl enable elasticsearch.service
    sudo systemctl start elasticsearch.service

    # Verify (with or without cert)
    curl -X GET --cacert /etc/elasticsearch/certs/http_ca.crt -u elastic:YOUR_ELASTIC_PASSWORD "https://localhost:9200/?pretty"
    curl -X GET --insecure -u elastic:<YOUR_ELASTIC_PASSWORD> "https://localhost:9200/?pretty"
    ```

    * Replace `<YOUR_ELASTIC_PASSWORD>` with your Elastic password.
4.  Install the APIM Components (ZIP) using the following commands:

    ```bash
    # Unzip and copy
    unzip graviteeio-full-4.13.0.zip
    cp -r graviteeio-full-4.13.0/graviteeio-apim-gateway-4.13.0 <DESTINATION_FOLDER>/
    cp -r graviteeio-full-4.13.0/graviteeio-apim-rest-api-4.13.0 <DESTINATION_FOLDER>/
    cp -r graviteeio-full-4.13.0/graviteeio-apim-console-ui-4.13.0 <DESTINATION_FOLDER>/
    cp -r graviteeio-full-4.13.0/graviteeio-apim-portal-ui-4.13.0 <DESTINATION_FOLDER>/
    ```

    * Replace `4.13.0` with the version that you downloaded.
    * Replace `<DESTINATION_FOLDER>` with the path to the folder in which to store the component.
5.  To start the APIM Gateway, use the following commands:

    ```bash
    cd <DESTINATION_FOLDER>/graviteeio-apim-gateway-4.13.0
    ./bin/gravitee
    ```

    * The Gateway listens on port `8082`.
6.  To start the Management API, open a new terminal, and then use the following commands:

    ```bash
    cd <DESTINATION_FOLDER>/graviteeio-apim-rest-api-4.13.0
    ./bin/gravitee
    ```

    * The Management API listens on port `8083`.
7.  Serve the Console and the Developer Portal with Nginx or another HTTP server. The `graviteeio-apim-console-ui-4.13.0` and `graviteeio-apim-portal-ui-4.13.0` folders contain static files, so starting the Gateway or the Management API doesn't open them. To serve them, complete the following steps:
    1. Open `<DESTINATION_FOLDER>/graviteeio-apim-console-ui-4.13.0/constants.json`, and then set `baseURL` to the Management API URL:

        ```json
        "baseURL": "http://localhost:8083/management",
        ```
    2. Open `<DESTINATION_FOLDER>/graviteeio-apim-portal-ui-4.13.0/assets/config.json`, and then set `baseURL` to the Management API Portal URL:

        ```json
        "baseURL": "http://localhost:8083/portal",
        ```
    3. Configure your HTTP server to serve the `graviteeio-apim-console-ui-4.13.0` folder on port `8084` and the `graviteeio-apim-portal-ui-4.13.0` folder on port `8085`.

{% hint style="info" %}
You can also run the Gateway and the Management API as daemons:

1.  To run a component as a daemon, use the following command from the component's folder:

    ```bash
    ./bin/gravitee -d -p=/var/run/gio.pid
    # Logs in $GRAVITEE_HOME/logs/
    ```
2.  To stop a component running as a daemon, use the following command:

    ```bash
    kill \`cat /var/run/gio.pid\`
    ```
{% endhint %}

## Verification

{% hint style="info" %}
The services may take a few minutes to initialize.
{% endhint %}

To verify that you installed Gravitee APIM correctly, complete the following steps:

*   Use the following command:

    ```bash
    curl -X GET http://localhost:8082/
    ```

    The command returns the following message: `No context-path matches the request URI` .
* Ensure that you can access the Management Console and the Developer Portal on the ports that your HTTP server serves them on:
  * To access the Management Console, go to `http://localhost:8084`. By default, the username and password are both `admin`.
  * To access the Developer Portal, go to `http://localhost:8085`. By default, the username and password are both `admin`.

## Enable Federation <a href="#enable-federation" id="enable-federation"></a>

Federation is disabled by default. To enable Federation on a `.zip` installation, update the Management API `gravitee.yml` configuration file and restart the Management API.

#### Enable Federation with .zip <a href="#enable-federation-with-zip" id="enable-federation-with-zip"></a>

To enable Federation, complete the following steps:

1. Open the Management API configuration file at `<DESTINATION_FOLDER>/graviteeio-apim-rest-api-4.13.0/config/gravitee.yml`, where `<DESTINATION_FOLDER>` is the directory in which you installed the APIM components.
2.  Locate the `integration` section and set `enabled` to `true`.

    ```yaml
    # Integration
    integration:
      enabled: true
      controller:
        ws:
          port: 8072
    ```

    The `integration.controller.ws.port` value is the WebSocket port that federation agents use to connect to the Management API. The shipped `gravitee.yml` pre-configures this port to `8072`.
3. Save the file.
4.  Restart the Management API to apply the change. To start the Management API, run the following commands:

    ```bash
    cd <DESTINATION_FOLDER>/graviteeio-apim-rest-api-4.13.0

    ./bin/gravitee
    ```

{% hint style="info" %}
If you run multiple APIM instances for high availability, you also need to set up cluster mode with Hazelcast to ensure data synchronisation across all instances. For cluster mode configuration, see [Set up cluster mode](docker/docker-compose.md#set-up-cluster-mode) on the Docker Compose installation page.
{% endhint %}
