# Get Started with API Designer

Before you can use the API Designer, you must first create a [Gravitee Cloud](https://cockpit.gravitee.io/) account. Once you register or sign in, you click on **API Designer** in the left nav.

<figure><img src="../../.gitbook/assets/api designer.png" alt="The Cloud dashboard with API Designer in the left navigation menu, beside counters for organizations, environments, installations, and nodes."><figcaption></figcaption></figure>

Get started with the [API Designer Workspace](../guides/api-designer-workspace/README.md) to create, manage, and configure your API designs.
